# ORMIS SAR — publicação de teste

Aplicação independente para GitHub Pages e integração no ArcGIS Experience Builder.

## Publicação
1. Crie um repositório próprio chamado `ormis-sar-testes`.
2. Extraia este ZIP e envie **os ficheiros da raiz**, incluindo `index.html`, para a raiz do repositório.
3. Em Settings → Pages, selecione Deploy from a branch → main → / (root).
4. Utilize `https://SEU_UTILIZADOR.github.io/ormis-sar-testes/` no widget Incorporar do separador adequado no Experience Builder.

## Segurança e arquivo
GitHub Pages convencional é público. **Não introduza dados reais, pessoais ou sensíveis nesta versão de testes.** Não equivale a controlo de acesso por chefe de sala.
A geração de PDF é local no navegador; o chefe de sala escolhe onde guardar o ficheiro no servidor da organização.
O repositório não recebe os PDFs. A numeração partilhada entre FF e SAR é introduzida manualmente e não impede duplicados.

Esta publicação não valida autenticação, compatibilidade com iframe nem funcionamento de impressão dentro do Experience Builder. Teste tudo antes de usar operacionalmente.
